This is a simple REST API for managing a list of books. It is created using Node.js and Express.

what is done:

made a basic express server that runs on port 3000.
created routes to get all books, add a book, update a book, and delete a book.
tested all routes using Postman.

what is learnt:

understanding what a rest api is.
using express to make routes.
using different http methods (get, post, put, delete).
sending and receiving json data.
